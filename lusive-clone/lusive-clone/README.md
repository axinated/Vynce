# lusive-clone

This project is a clone of the website lusive.xyz, built using HTML, CSS, and JavaScript. The goal is to replicate the design and functionality of the original site while providing a clean and maintainable codebase.

## Project Structure

```
lusive-clone
├── src
│   ├── index.html          # Main HTML file
│   ├── styles              # Contains CSS files
│   │   ├── main.css        # Main styles for the website
│   │   └── components.css   # Styles for individual components
│   ├── scripts             # Contains JavaScript files
│   │   └── main.js         # Main JavaScript file for interactivity
│   └── components          # Contains reusable HTML components
│       ├── header.html     # Header component
│       ├── hero.html       # Hero section component
│       ├── showcase.html    # Showcase section component
│       ├── about.html      # About section component
│       └── footer.html     # Footer component
├── public
│   └── fonts               # Contains font files
│       └── README.md       # Information about fonts used
├── package.json            # npm configuration file
├── .gitignore              # Files to ignore in version control
└── README.md               # Project documentation
```

## Getting Started

To get started with the project, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd lusive-clone
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm run dev
   ```

5. Open your browser and go to `http://localhost:3000` to view the website.

## Features

- Responsive design that adapts to various screen sizes.
- Interactive components for enhanced user experience.
- Clean and organized code structure for easy maintenance.
